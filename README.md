# Эмулятор командной оболочки ОС

Практическая работа №1 по дисциплине «Конфигурационное управление».
Вариант №6, этап 1 — REPL.

## Общее описание

Консольный эмулятор командной оболочки UNIX-подобной ОС.
На первом этапе реализован минимальный REPL-прототип:

- приглашение к вводу формируется из реальных данных ОС
  (`username@hostname:~$`);
- парсер разбирает ввод на команду и аргументы по пробелам;
- реализованы команды-заглушки `ls` и `cd`, выводящие своё имя
  и аргументы;
- реализована команда `exit` для выхода;
- предусмотрена обработка ошибок (неизвестная команда).

## Функции и настройки

| Команда | Описание |
|---------|----------|
| `ls [args]` | Заглушка: печатает `ls: args=[...]` |
| `cd [args]` | Заглушка: печатает `cd: args=[...]` |
| `exit` | Завершает работу эмулятора |

Настроек на этом этапе нет.

## Сборка и запуск

Зависимостей нет, требуется Python 3.10+.

Запуск эмулятора:

```bash
./run.sh
```

Запуск тестов:

```bash
python3 -m unittest discover -s tests
```

## Примеры использования

```
user@host:~$ ls
ls: args=[]
user@host:~$ cd /tmp
cd: args=['/tmp']
user@host:~$ unknown
unknown: command not found
user@host:~$ exit
Bye!
```
