## Этап 2. Конфигурация

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH`    | Путь к физическому расположению VFS |
| `--script PATH` | Путь к стартовому скрипту с командами |

При запуске эмулятор печатает отладочную информацию обо всех
переданных параметрах.

### Стартовый скрипт

Скрипт — это текстовый файл, по одной команде на строку.
Поддерживаются:

- комментарии, начинающиеся с `#`;
- пустые строки (игнорируются);
- любые команды эмулятора (`ls`, `cd`, `exit`).

При выполнении скрипта на экран выводится как ввод (команда),
так и вывод, имитируя диалог с пользователем.

Пример: `scripts/startup.cmds`.

### Скрипты реальной ОС (Windows)

В папке `scripts/` лежат `.bat`-файлы для запуска эмулятора
с разными наборами параметров:

| Скрипт | Что делает |
|--------|------------|
| `run_basic.bat`         | Запускает эмулятор без параметров |
| `run_with_script.bat`   | Запускает эмулятор со стартовым скриптом |
| `run_with_all_params.bat` | Запускает эмулятор с VFS и скриптом |

### Пример запуска

```bat
scripts\run_with_all_params.bat

### Windows

Запуск через `run.bat`:

    run.bat

Со стартовым скриптом:

    run.bat --script scripts\startup.cmds

### Linux / macOS

Запуск через `run.sh`:

    ./run.sh
